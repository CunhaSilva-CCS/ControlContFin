Política de Privacidade — ControlContFin

Última atualização: [data de publicação]

O ControlContFin é um aplicativo de controle financeiro pessoal para iOS e Android. Esta Política de Privacidade explica, de forma direta, como o aplicativo trata os dados do usuário.

Resumo em uma frase: o ControlContFin não coleta, não transmite e não armazena nenhum dado do usuário em servidores — tudo fica apenas no aparelho do próprio usuário, dentro de um banco de dados criptografado.

1. Quais dados o aplicativo trata

O aplicativo trabalha com dados financeiros que o próprio usuário insere manualmente: contas, transações, categorias, orçamentos e metas. Todos esses dados:

  • São armazenados exclusivamente no aparelho do usuário, num banco de dados SQLite protegido por criptografia (SQLCipher).
  • Nunca são enviados para nenhum servidor — o ControlContFin não possui nenhum backend, API remota ou serviço de nuvem associado.
  • Não são compartilhados com terceiros, porque não existe nenhum mecanismo de compartilhamento automático no aplicativo.

2. Autenticação (PIN e biometria)

  • O PIN de bloqueio do aplicativo é armazenado apenas como um hash criptográfico salgado (PBKDF2), guardado no armazenamento seguro do sistema operacional (Keychain no iOS, Keystore no Android) — nunca em texto simples, nunca fora do aparelho.
  • Quando o usuário opta por usar biometria (Face ID, Touch ID ou impressão digital), o aplicativo nunca recebe o dado biométrico em si. Toda a verificação é feita pelo próprio sistema operacional, que devolve ao aplicativo apenas um resultado de sucesso ou falha.

3. Notificações

O aplicativo pode enviar lembretes locais sobre transações recorrentes programadas pelo usuário. Essas notificações são agendadas e disparadas inteiramente pelo sistema operacional do aparelho — não existe nenhum servidor de push envolvido, e nenhum dado é enviado para fora do aparelho para gerar essas notificações.

4. Backup manual

O aplicativo permite exportar um arquivo de backup criptografado, a pedido do próprio usuário. Esse arquivo é entregue diretamente ao usuário (por exemplo, através do menu de compartilhamento do sistema), que decide onde guardá-lo. O desenvolvedor do ControlContFin nunca tem acesso a esse arquivo ou ao seu conteúdo.

5. Contas, login e serviços de terceiros

O ControlContFin não exige criação de conta, não possui login, não integra nenhum provedor de identidade de terceiros, não utiliza ferramentas de análise de uso (analytics), não exibe anúncios e não incorpora nenhum SDK de terceiros com finalidade de coleta de dados.

6. Seus direitos (LGPD)

Nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018), o titular dos dados tem direito a acesso, correção, eliminação, portabilidade e demais garantias previstas em lei. Como todos os dados do ControlContFin já estão inteiramente sob controle do próprio usuário, no seu próprio aparelho, esses direitos são exercidos diretamente:

  • Acesso e correção: qualquer dado pode ser visualizado e editado diretamente nas telas do aplicativo.
  • Eliminação: apagar um registro no aplicativo o remove permanentemente; desinstalar o aplicativo remove todos os dados do aparelho.
  • Portabilidade: a função de exportação (CSV/JSON ou backup completo) permite ao usuário levar seus dados para onde quiser, a qualquer momento.

Como o desenvolvedor nunca recebe nem armazena esses dados, não há nada a solicitar por e-mail ou formulário — o controle já está inteiramente nas mãos do usuário.

7. Crianças e adolescentes

O aplicativo não é direcionado a crianças e não coleta, de forma consciente, dados de menores de idade — nem de nenhum outro usuário, já que nenhum dado é coletado pelo desenvolvedor em nenhuma hipótese.
